## 🏛️ Спринт 1: Посольство Японии (GGP / Kusanone)
### ⏱️ Срок: 7-10 дней | Бюджет: $70,000 - $90,000 | Статус: 🟡 В РАБОТЕ (СПЕЦИФИКАЦИЯ И СМЕТА)
- [x] **Шаг 1.1:** Концепт SAFI Women's Empowerment HUB получен и декомпозирован под капитальные затраты
- [ ] **Шаг 1.2:** Верификация помещения под хаб (г. Худжанд, договор аренды/безвозмездного пользования)
- [ ] **Шаг 1.3:** Формирование спецификации и сбор 3 коммерческих предложений (КП) от поставщиков:
  - [ ] Промышленные швейные машины (прямострочные, оверлоки, вышивальные)
  - [ ] Раскройное и влажно-тепловое (утюжильное) оборудование
  - [ ] Оборудование учебного IT-класса (компьютеры для цифровых навыков и онлайн-продаж)
- [ ] **Шаг 1.4:** Заполнение официальной аппликационной формы Посольства Японии (GGP)
  - [ ] Обоснование социально-экономической уязвимости женщин Согда
  - [ ] Технико-экономическое обоснование выбора оборудования
  - [ ] План долгосрочной устойчивости и самоокупаемости через бренд SafiDecor
- [ ] **Шаг 1.5:** Формирование и визирование бумажного пакета (печать, подпись, сопроводительное письмо)
- [ ] **Шаг 1.6:** Подача в Посольство Японии в Душанбе (ул. Хабибулло Назарова 65/1)
